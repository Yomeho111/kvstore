# Stop:    SIGTERM -> main.cpp handler() -> exit()
#
# Result:  "All heap blocks were freed -- no leaks are possible", 0 errors,
#          907,862 allocs == 907,862 frees.
#
#          Switching the signal handler from _exit() to exit() is what made the
#          report completely clean. exit() runs the atexit/static destructors and
#          _dl_fini, so glibc releases the __cxa_thread_atexit TLS record and
#          libnl-3 / libnl-route-3 tear down the translation table they build in
#          their ELF constructors. Under _exit() those 21 blocks (420 B) stayed
#          mapped and had to be filtered with memory_probe/valgrind.supp.
#
#          Caveat: this run used role = standalone. With role = master or slave
#          the static destructors also join the replication thread, which is the
#          shutdown hang the original _exit() comment warned about.
